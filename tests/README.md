# Running Tests

## Running the tests

To run the tests, run `pytest` from the root of the repository.

```bash
pytest
```

This will run the tests and print the results. If you want to see the output of the tests, you can use the `-v` flag.

```bash
pytest -v
```

## Running the tests in a specific directory

To run the tests in a specific directory, you can use the `-k` flag to specify a keyword. This will run all the tests that have the keyword in their name.

```bash
pytest -k "test_trainer"
```

This will run all the tests that have `test_trainer` in their name.

## Running the tests in a specific file

To run the tests in a specific file, you can use the `-m` flag to specify the name of the file. This will run all the tests in that file.

```bash
pytest -m "trainer"
```

This will run all the tests in the `trainer` file.

## Running the tests in a specific module

To run the tests in a specific module, you can use the `-m` flag to specify the name of the module. This will run all the tests in that module.


This will run all the tests in the `trainer` module.
